# TextToolBox
TextToolBox is an online text processing toolkit that helps users clean garbled text, remove blank lines, convert full-width characters, and compare text differences. It is designed for PDF text, webpage copy, WeChat messages, and document cleanup, with a simple paste-and-process workflow that requires no sign-up.
# 文本工具盒
文本工具盒 是一个在线文本处理工具站，提供清理乱码、去除空白行、全角转半角和文本比对等实用工具，适合处理 PDF、网页、微信和文档复制内容中的杂乱字符与格式问题。无需注册，直接粘贴文本即可快速处理。
